What the challenge tests

  • Write clear, structured prompts with useful constraints.
  • Use AI tools critically instead of accepting the first answer.
  • Think creatively and validate the result.
  • Explain your process and final result confidently.
Core formula

The CRAFT prompt method

Context — background and situation
Role — expertise the AI should adopt
Action — exact task to perform
Format — structure of the answer
Target — audience, constraints and success criteria

Add examples and ask the AI to state assumptions when the task is ambiguous.

Prompt patterns to remember

1. Break it downFirst identify the requirements. Then propose 3 approaches, compare them against the constraints, and recommend one with reasons.
2. Critique and improveReview the answer for factual errors, missing requirements, unclear assumptions and edge cases. Give a corrected final version and list the changes.
3. Learn by exampleShow one simple example, explain why it works, then create a similar practice task for me without revealing the answer.
4. Structured outputReturn: objective, assumptions, solution, implementation steps, risks, validation checklist and success metrics. Use concise language.

During the challenge

Use this 6-step loop

  1. Read twice: underline the deliverable, audience and restrictions.
  2. Clarify: identify missing details; state reasonable assumptions.
  3. Plan: split complex tasks into small steps.
  4. Prompt: use CRAFT and specify the output format.
  5. Verify: test facts, calculations, logic, safety and edge cases.
  6. Present: give the result first, then reasoning and evidence.
Avoid these mistakes

Common score killers

  • Vague prompts such as “make it better”.
  • Forgetting audience, constraints or output format.
  • Trusting fabricated facts, sources or code without checking.
  • Overcomplicating a simple task.
  • Giving an idea without explaining how it will work.
  • Failing to connect the result to the user's actual problem.
