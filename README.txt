PROMPTWARS — ULTIMATE AI CHALLENGE KIT

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in Chrome, Safari, Edge or Firefox.
3. No installation, account, internet connection or API key is required.
4. Navigate using the tabs:
   - Start here: challenge overview and readiness checklist.
   - Prompt lab: build a reusable CRAFT prompt.
   - Mock challenge: practise three tasks against a 10-minute timer and self-score.
   - Quiz arena: 15 multiple-choice questions with explanations.
   - Project studio: explore mini-project ideas and generate a 60-second pitch.
   - Winning strategy: workflow and final checklist.

IMPORTANT
This is an independent preparation resource, not an official PromptWars product or affiliation.
The prompt builder creates text only; paste it into the AI tool permitted by your challenge rules.
The mock challenge score is self-assessed and is not an official competition score.
